To compare the difference in embedding returns, Two models are used:
- qwen3-embedding:4b
- qwen3-embedding:0.6b

the 4b model returns a 2560 dimensional array, while the 0.6b returns a 1024dim length vector.
Both models can run on consumer class hardware, so the indicator creator can verify the result on its own.

The similarity thresholds range from 0 to 1, while 1 is exactly the same indicator, modified indicators range from 0.95 to 1, while stronger modifications return between 0.85 to 0.95
A logarithmic scale would be better to visualize the results. 

Two possible outcomes are possible: false positive: a indicator gets recognized as a child, while it actually isnt'it
false negative: a indicator gets not recognized as child, although its code is clearly evolved out of the parent.
